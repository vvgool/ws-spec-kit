# 设计技术方案

设计对着已确认规格，不发明需求。优先加深现有模块，不平行再造一套。

## 步骤

1. **钉规格**
   读 `specification` 与探索报告。完成：每个要动的行为都能指回规格句子。

2. **找 seam**
   标出将要切开的公共边界（入口、配置、Gate、适配器）。完成：能一句话说清「外面看见什么，里面藏什么」。

3. **写取舍**
   每个关键缝至少两个真方案，写清为何选这个。完成：落选方案有具体代价，不是空对比。

4. **交 `design`**
   写模块形状、数据流、失败方式和验证点。完成：实现者不用再猜接口；测试能钉在这些 seam 上。

## 规则

- 非法状态用类型消掉，不在调用点反复校验。
- 不扩允许路径，不引入未声明的外部写入。
- 规格未决：停止并报告阻塞，不把设计当拍板。
