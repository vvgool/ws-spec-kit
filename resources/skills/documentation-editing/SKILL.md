# 编辑中文文档

改文档是在更新缓存。每个陈述句都要指回已确认事实。

## 步骤

1. **读事实清单**
   完成：知道增、删、改哪几句。

2. **只改允许路径**
   在 `allowedPaths` 内编辑中文正文。完成：diff 不含代码、配置或范围外文件。

3. **交文档变更**
   完成：新增句都能指证；过时句已删或已改。

## 规则

- 先写清完成标准，再堆解释。
- 范围外或事实不足：停止并报告阻塞。
