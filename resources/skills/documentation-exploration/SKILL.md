# 探索文档事实

文档只陈述能指证的事实。代码、配置、帮助输出是真源；旧文档是待核缓存。

## 步骤

1. **钉范围**
   读允许的文档路径与目标。完成：知道哪些文件能改。

2. **对事实**
   每条将写入的句子都能指到源文件、命令或已确认原文。完成：过时文档被标成缓存，不当新事实。

3. **交事实清单**
   写出现状、缺口、过时句。完成：编辑者不用再猜 API 或行为。

## 规则

- 查得到的不抄进清单当永久正文，只记「到哪查」。
- 事实对不上：停止并报告阻塞。
