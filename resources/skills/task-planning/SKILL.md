# 拆分实施任务

一张任务做一件可观察行为。先做挡住别人的，再做被挡住的。

## 步骤

1. **读设计**
   对照 `specification` 与 `design`。完成：每个任务能指回一个设计缝或规格条款。

2. **切 tracer**
   按可独立验证的行为切开，写下阻塞边。完成：没有「做完功能 X」这种大篮子；环被拆开。

3. **标验证**
   每个任务写清红测会看见什么。完成：验收是命令或断言，不是「看起来对」。

4. **交 `tasks`**
   按阻塞序排列。完成：实现者可以一次只拿一张任务，不必回头猜依赖。

## 规则

- 实现与其测试是同一张任务。
- 目录不同且可独立回滚的，拆开。
- 设计缺口：停止并报告阻塞。
