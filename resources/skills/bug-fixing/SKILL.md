# 修复审查问题

修 finding 的根因。先让失败可复现，再改生产代码。

## 步骤

1. **钉 finding**
   只处理 `review-result` 里必须修的项。完成：每条能指出文件与失败观察。

2. **收紧 red**
   已有测试能红就用；否则补一条最小回归。完成：一条命令已经红在**这个**问题上。

3. **修根因**
   改共享缝一次，不在每个调用点打补丁。完成：那条 red 变绿，原 TDD 红测仍在。

4. **交回归证据**
   完成：列出修了哪条 finding、哪条测试钉住它。

## 规则

- 不顺手做下一张任务或新功能。
- 删测试让审查变绿，不算修复。
- 找不到可复现的 red：停止并报告阻塞。
