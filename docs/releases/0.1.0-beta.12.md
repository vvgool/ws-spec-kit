# 0.1.0-beta.12

本版修复内置工作流运行时缺失验证执行器，导致 Review-Fix 提交后无法继续的问题。

- 补齐默认 `quality.verify` 与 `quality.docs.integrity` 执行器；功能任务修复后由引擎重跑固定 Test Gate。
- 文档任务改由引擎执行真实完整性校验并生成可信 Evidence，覆盖基线以来的完整差异、未跟踪文件和循环修复新增文件，允许文档范围内的合法删除。
- 文档复验失败清除旧证据，修正后可重新领取并验证；复验成功生成独立 Evidence ID，保留关闭校验所需的原验证步骤绑定。
- 移除测试中掩盖默认执行器缺失的替身，新增真实 CLI 的成功、失败拦截及重试恢复回归。

## 更新

```sh
npm install -g ws-spec-kit@0.1.0-beta.12 --registry=https://registry.npmjs.org
wspec --version
```

本版未修改 Driver Skill，已安装的 Driver 无需因本次修复重装。

## 验证边界

本版发布到 npm `beta` 渠道。真实宿主及 Connector 平台验收仍以 `docs/acceptance/release-report.md` 为准，不能将本地自动化通过视为生产验收完成。

本地验证：全量 1,042/1,042 项测试通过（无失败、无跳过），lint、typecheck、发布基线与验收报告一致性检查通过。规范与功能正确性两路 review 均未发现阻断项。

最终 build 与干净消费者打包安装测试 3/3 通过，发布包包含新增文档门禁及默认执行器实现。
