# 0.1.0-beta.13

本版让任务目录与交付文档更容易阅读，同时保持已有任务和内部身份兼容。

- 新任务目录、工作树和分支使用需求名称加短编号；内部 Work Item ID 保持稳定，旧任务不迁移。
- Markdown 产物使用需求规格、技术方案、实施计划等职责名称，评审结果包含轮次，保留历史版本及完整摘要校验。
- 任务入口新增 README 导航与原始需求阅读副本，展示状态、阶段进度和交付资料；导航不会作为审批依据，也不会覆盖用户自有文件。
- Driver v13 从 Work Package 获取草稿目录，避免根据任务 ID 猜测路径。
- 兼容旧 Driver 在任务 ID 目录下生成草稿，避免测试配置迁移误报工作区已修改。
- 修复含中文的事件日志在中断恢复时按字符位置截断、损坏有效事件的问题。

## 更新

```sh
npm install -g ws-spec-kit@0.1.0-beta.13 --registry=https://registry.npmjs.org
wspec --version
```

已安装的 Driver 不会随 npm 更新自动改变。升级 Driver 时先移走旧 `SKILL.md`（需要保留时自行备份），再运行 `wspec agent install --client <codex|claude|cursor|generic>`；generic 需指定 `--target`。让 Host 重新加载 Skill 后使用 v13。
