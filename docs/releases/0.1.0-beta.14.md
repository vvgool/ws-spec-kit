# 0.1.0-beta.14

本版修复 Agent 把风险说明提交为字符串数组时，被 Schema 校验阻塞的问题。

- `SubmitResult.remainingRisks` 支持非空文字和结构化对象混用，保留原始说明及对象字段。
- 文字用于记录，不自动推断风险等级；结构化风险继续参与 Profile 选择与升级。
- 纯空白文字、null、数字、布尔和数组仍被拒绝。`commands`、`evidence`、`externalWrites` 仍要求对象，文字风险不能替代可信证据。
- 同步公开类型、嵌套及独立 JSON Schema、协议文档，并覆盖实际提交、幂等重试和风险分级行为。
